The product, Merge, is a premium, data-driven dating application with a sophisticated, dark-themed aesthetic. The core of the application revolves around a high-quality user experience, prioritizing an elegant and intuitive interface.

**Implemented Features & Design:**
-   **Hinge-Inspired Profile Tab:** The main profile screen has been completely redesigned to emulate the Hinge app's layout. It features a circular profile picture with a completion progress ring, a tabbed interface (Get More, Safety, My Merge), and a unified scrolling experience.
-   **Centralized Editing:** All user profile information is edited through an Edit Profile modal. This includes basic information, My Vibe (music), lifestyle choices, and visibility controls.
-   **Settings Modal:** A dedicated settings area, accessed via a gear icon on the profile page, contains privacy, discovery, and premium-locked features like hiding age or distance.
-   **Swipe Cards (Discover/Home):** The main discovery feature uses swipeable profile cards. These cards can be expanded to show detailed information, including AI-generated compatibility insights.
-   **UI Testing with Mock Data:** Due to authentication complexities, the app currently runs in a test mode using a mock user. This allows for full UI/UX testing of all components without requiring a backend connection, enabling rapid iteration on visual design and functionality. The swipe cards are also populated with mock profiles.
