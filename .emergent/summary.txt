<product_requirements>
The product, Merge, is a data-driven, premium dating application focused on intelligent connections. It features a sophisticated dark theme aesthetic with a black background and blue/purple/pink accents.

**Core Features Implemented:**
-   **Profile Tab:** A central dashboard for user identity. It has undergone multiple redesigns to improve visual hierarchy and user experience. It displays user info, editable interests (with a smart-autocomplete input), and an About Me section.
-   **Photo Management:** Users can upload, change, and manage their profile photos via a . Photos are stored on Cloudinary.
-   **My Vibe (Universal Music):** A universal song search feature powered by the Deezer API allows all users to add a vibe song to their profile, complete with a 30-second preview player. This replaced a Spotify-only implementation to ensure global accessibility.
-   **Merge Wheel (Gamified Feature):** Rebranded from Connection Matrix, this is a daily spin-the-wheel game to earn rewards. It has been moved to the profile header and styled with a sophisticated, techy data-visualization aesthetic.

The application aims for a modern, clean, and interactive user experience, taking inspiration from leading dating apps while maintaining a unique, tech-forward identity.
